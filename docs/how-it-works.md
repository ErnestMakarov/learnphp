# Как устроен LearnPHP

Проект использует обычный PHP без Laravel. Общая структура соответствует учебному примеру
преподавателя: маршруты, контроллеры, модели и шаблоны. Исходные упражнения сохранены в
`exercises/lesson-functions.php`, старые записи — в `docs/lesson-notes.md`.

## От ссылки до страницы

Например, браузер открывает `/admin/users`:

1. `public/index.php` подключает загрузчик классов, запускает сессию и читает `routes.php`.
2. `Router` ищет совпадение адреса и HTTP-метода. GET `/admin/users` связан с `UsersController::index()`.
3. Конструктор `UsersController` проверяет, что вошедший пользователь — администратор.
4. Метод `index()` получает пользователей через `User::all()`.
5. Модель обращается к `DB`, который выполняет SQL-запрос через PDO.
6. `view('users/index', ...)` передаёт массив пользователей шаблону `views/users/index.php`.
7. Цикл `foreach` выводит строки таблицы. Браузер получает готовый HTML.

## Что означает CRUD

| Действие | Метод контроллера | Что происходит |
| --- | --- | --- |
| Create — создание | `create()` и `store()` | GET показывает форму, POST проверяет данные и сохраняет нового пользователя |
| Read — чтение | `index()` и `view()` | Список всех пользователей или карточка по ID |
| Update — изменение | `edit()` и `update()` | GET показывает текущие данные, POST сохраняет изменения |
| Delete — удаление | `delete()` | POST удаляет пользователя по ID |

У GET-запроса ID находится в адресе, например `?id=2`, и читается из `$_GET`.
У POST-запроса ID находится в скрытом поле формы и читается из `$_POST`.
`requestId()` проверяет, что это положительное целое число. Если записи нет, ответ — 404.

После успешного POST вызывается `redirect('/admin/users')`: браузер получает код 303 и
делает новый GET-запрос. Благодаря этому обновление страницы не отправляет форму повторно.

## Пароли, сессии и защита форм

- `password_hash(..., PASSWORD_BCRYPT)` создаёт хеш. Сам пароль в базу не записывается.
- `password_verify()` при входе проверяет пароль по сохранённому хешу.
- Пустые поля пароля при редактировании означают «оставить текущий пароль».
- `$_SESSION['userID']` хранит ID вошедшего пользователя на сервере. Браузер хранит cookie
  с идентификатором сессии; пароль в эту cookie не помещается.
- При входе идентификатор сессии меняется через `session_regenerate_id(true)`.
- CSRF-токен связывает POST-форму с сессией. Без правильного токена изменение отклоняется.
- SQL-запросы используют параметры `?`: значения передаются отдельно от SQL-кода.
- `e()` экранирует текст для HTML, чтобы имя вроде `<script>...</script>` отображалось текстом.
- `is_admin` определяет доступ к управлению. Обычный пользователь может войти, но получит 403
  при попытке открыть админку. Формы создания и изменения не позволяют повысить роль.

## Чем Tech отличается от World

`PublicController::tech()` задаёт свой `$posts`, затем подключает `views/tech.php`.
Шаблон использует те же части страницы, что и `views/us.php`: header, posts, sidebar и footer.
`Route::get('/tech', ...)` связывает адрес с методом, а меню содержит ссылку `href="/tech"`.
World и U.S. показывают статьи из базы, Tech — собственные технологические посты из контроллера.

## Composer и регистрация

`bootstrap.php` подключает `vendor/autoload.php`. Composer использует правило PSR-4
`App\\` → `src/`: например, `App\\Models\\User` находится в `src/Models/User.php`.
Пакет `symfony/var-dumper` предоставляет `dump()` и `dd()`; своих дубликатов нет.
После клонирования нужен `composer install`, потому что `vendor/` не хранится в Git.

`AuthController::register()` создаёт обычного пользователя. Общая проверка данных
находится в `UserInput::validate()`, поэтому правила регистрации и создания через админку
одинаковые. После регистрации ID записывается в сессию, а её идентификатор обновляется.
Права администратора через форму регистрации получить нельзя.

## Маршруты и формы

`Route` хранит метод, путь и действие в приватных свойствах с getter-методами.
`Route::get()` и `Route::post()` добавляют объекты в `Router`. Он сравнивает **и путь,
и HTTP-метод**, игнорируя query string. Контроллер вызывается только после совпадения.
Неподдерживаемый метод получает 405, неизвестный путь — 404.

`/forms` демонстрирует один адрес с двумя действиями: GET показывает форму,
POST читает `$_POST` и выводит экранированное приветствие. `view()` использует
`extract(..., EXTR_SKIP)`, а публичные страницы передают данные через `compact()`.

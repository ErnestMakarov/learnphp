# Краткие заметки по PHP

Ранние упражнения запускаются отдельно: `php exercises/basics.php`.
`exercises/lesson-functions.php` сохранён как первоначальный конспект; код после `return`
там намеренно недостижим и показывает, почему возврат завершает функцию.

- `echo` выводит текст, `return` возвращает значение вызывающему коду.
- `$a + $b` для массивов объединяет ключи и сохраняет совпадающие значения слева.
  `array_merge()` добавляет числовые элементы и перенумеровывает их.
- `foreach` перебирает элементы, `do ... while` запускается хотя бы один раз.
- Рекурсии нужен базовый случай, иначе вызовы не остановятся.
- `$b = $a` для объекта копирует ссылку, `clone $a` создаёт другой объект.
- `public` доступен снаружи, `protected` — классу и наследникам, `private` — самому классу.
- `interface` задаёт обязательные методы, `trait` даёт повторно используемую реализацию.
- `__construct` вызывается при создании, `__toString` — при приведении объекта к строке.
- `static` относится к классу; `static::` учитывает класс, из которого вызван метод.
- `include` позволяет собирать HTML из partial-файлов; `<?= e($value) ?>` выводит экранированный текст.
- `compact('posts')` создаёт массив с ключом `posts`; `extract()` создаёт переменные для шаблона.
- GET читает страницу, POST отправляет изменение. Поле формы передаётся по атрибуту `name`.
- PDO-параметры передают значения отдельно от SQL. `FETCH_CLASS` создаёт экземпляры моделей.
- Cookie хранится в браузере; данные сессии хранятся на сервере.
- Хеширование не является шифрованием: пароль проверяют через `password_verify`, а не расшифровывают.
- Composer устанавливает пакеты из lock-файла и создаёт PSR-4 загрузчик.
